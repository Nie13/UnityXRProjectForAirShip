# Air ship (VR Game with Unity)
This project is full VR interactable with hands. Player can switch between different seats to operate different parts of this air ship.

## Demo
A short demo video is available here: https://drive.google.com/file/d/1igBso6hzdmuEoiHCpx6rH8p66L33xzC8/view?usp=drive_link 

### Roles
Supported roles list:
- captain (to control the ship direction),
- chief mate (to control the height and speed of the ship),
- main gunner (to control the cannon on top of the deck),
- machine gunner * 2 (control the machine gun on left and right side),
- engine operator (to control the engine and make minor modifications)
